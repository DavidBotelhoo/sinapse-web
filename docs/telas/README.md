# Telas aprovadas do Sinapse

Cada tela e cada estado que foi desenhado e aprovado, nos temas claro (Plantão) e escuro (Madrugada), no desktop (1440px) e no celular (390px). É a referência visual: o app pronto tem que ficar igual.

## O que tem aqui

```
desktop/claro/   desktop/escuro/    PNG (2×) e SVG de cada estado
celular/claro/   celular/escuro/
desktop/html/    celular/html/      HTML estático de cada estado (tema claro)
fonte/                              arquivos-fonte do editor de design, com a lógica de estado
```

- **PNG** é a referência de pixel, em 2× (uma tela de 1440px tem 2880px de largura).
- **SVG** é a mesma imagem em vetor. O texto vem em contornos (não é texto selecionável); os textos exatos estão no HTML.
- **HTML** é a tela montada, com as classes `sn-*` do design system e as classes locais da tela num `<style>` no próprio arquivo. Abra no navegador (Chrome ou Edge; precisa ler arquivos locais, então abra pelo explorador de arquivos ou rode `npx serve docs`). Para ver no escuro, troque `data-theme="light"` por `data-theme="dark"` no primeiro `div` dentro de `#root`.
- **Fonte** (`fonte/*.dc.html`) é o formato do editor de design: marcação com `{{campos}}`, `<sc-for>` e `<sc-if>`, e uma classe `Component` com `renderVals()` que guarda o estado (aba escolhida, filtros, card virado, avaliações). Leia para entender o comportamento das interações; não copie como código.

Telas do celular presas à altura do aparelho (a folha de filtros e o modal de senha) foram cortadas em 844px, a altura de um celular.

## Regras de leitura

- O desktop e o celular de uma linha são **a mesma rota**, responsiva: a sidebar some abaixo de 768px e a barra inferior aparece.
- A sessão de estudo não tem sidebar nem barra inferior (layout de foco).
- Dados nas telas são exemplos realistas (Ana Souza, decks de Farmacologia, Fisiologia, Anatomia…). No app, tudo vem da API.
- Preços aparecem como "R$ [preço]": ainda não foram definidos.
- Hover, foco e animações estão no `components/bundle.css` e nos READMEs dos componentes; as imagens mostram o estado parado.
